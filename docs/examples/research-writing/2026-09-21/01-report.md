# 入力解像度：448を次の基準に採用する

> 見本01・A：決まった項目順で読む。架空の実験001。

- **目的**：入力を大きくすると、細かい傷の見逃しが減るか。
- **結果**：macro F1は81.6 → 83.4。3 seedすべてで改善した。
- **判断**：448入力を採用し、残る誤りを調べる。
- **範囲**：開発評価2,000枚での結果。未知の撮影条件での効果は未確認。

## 比較条件

- **変更**：入力解像度を224 → 448。
- **固定**：モデル構造、学習データ、学習率、epoch数、batch size。
- **採用基準**：平均F1が+1.0ポイント以上、推論30ms/枚以下。

## 結果

| 指標 | 224入力 | 448入力 |
|---|---:|---:|
| macro F1・3 seed平均 | 81.6 | 83.4 |
| seed別のF1 | 81.4 / 81.8 / 81.6 | 83.4 / 83.6 / 83.2 |
| 細かい傷100枚の正解数・seed 0 | 60 | 78 |
| 推論時間・ms/枚 | 10 | 24 |

- **改善幅**：seed別で+2.0 / +1.8 / +1.6ポイント。
- **速度**：推論は2.4倍の時間を要するが、上限内。同一機器・batch size 16で測定。
- **未計測**：学習時間。

## 解釈と限界

- **観察**：傷100枚では、新たな正解22枚、逆に不正解になったもの4枚。
- **手がかり**：新たな正解22枚のうち15枚は、元画像上の傷幅が2〜4画素だった。
- **解釈**：解像度を上げて、細い傷の情報を残せた可能性がある。
- **限界**：傷の内訳はseed 0のみ。改善の仕組みまでは特定できていない。

## 次にすること

- 448でも誤る画像を確認し、細部・撮影条件・分類基準のどこに課題があるかを調べる。
- 448より大きい入力での学習は、まだ計画していない。
