## 今回そろえた書き方

- **冒頭**：目的・結果・判断・限界を短い箇条書きにする。
- **見出し**：何を読める場所か、見出しだけで分かる名前にする。
- **箇条書き**：一項目に一つの論点。必要なものには先頭ラベルを付ける。
- **比較**：数値は表に並べる。重要な制約は結果の近くに残す。
- **詳しい情報**：共通設定や関連ページへリンクする。
